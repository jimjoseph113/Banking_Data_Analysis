
#  Banking Data Analysis Project

##  Overview

This project analyzes banking data to uncover insights into customer behavior, transaction patterns, fraud detection, and loan risk.

##  Objectives

* Identify high-value customers
* Detect potential fraudulent transactions
* Analyze transaction trends
* Evaluate loan risk

## 🛠 Tools Used

* SQL (Data Analysis)
* Power BI (Data Visualization)

##  Key Insights

* A small group of customers contributes most of the transaction value
* High-value transactions may indicate potential fraud
* Some customers with loans have low balances, indicating risk
* Customer distribution is balanced across countries
